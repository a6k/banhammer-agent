# BanHammer Agent

Lightweight server agent that monitors Fail2Ban activity and serves a local REST API. Connects directly to the [BanHammer](https://github.com/a6k) macOS/iOS app — no central server required. Your data stays on your server.

## How it works

```
[Your Server]
  └── banhammer-agent
        ├── Monitors Fail2Ban logs and jails
        ├── Stores events in local SQLite database
        └── Serves HTTPS API for the BanHammer app
              ↑
[BanHammer App] ← connects directly
```

## Quick Start

### 1. Install

```bash
pip install banhammer-agent
```

### 2. Initialize

```bash
sudo banhammer-agent init
```

This generates an API key and creates `/etc/banhammer/config.toml`. **Save the API key** — you'll need it in the BanHammer app.

### 3. Run

```bash
sudo banhammer-agent run
```

Or install as a systemd service:

```bash
sudo cp systemd/banhammer-agent.service /etc/systemd/system/
sudo systemctl enable --now banhammer-agent
```

### 4. Connect the app

Open the BanHammer app, add your server with the URL and API key from step 2.

## API

The agent serves a REST API on port 8443 (configurable).

| Method | Endpoint | Auth | Description |
|--------|----------|------|-------------|
| GET | `/api/v1/health` | No | Version and hostname |
| GET | `/api/v1/status` | API-Key | Jail status with active bans, IPs, log context |
| GET | `/api/v1/events` | API-Key | Ban/unban events (paginated) |
| GET | `/api/v1/stats` | API-Key | Top attackers, bans by jail |
| POST | `/api/v1/unban` | API-Key | Unban an IP from a jail |

Auth header: `Authorization: Bearer bh_your_api_key`

Interactive API docs available at `http://your-server:8443/docs` (FastAPI/Swagger).

## Deployment

### Behind Nginx (recommended)

The agent listens on localhost:8443. Nginx handles SSL:

```nginx
server {
    listen 443 ssl;
    server_name bh.example.com;
    # SSL managed by Certbot

    location / {
        proxy_pass http://127.0.0.1:8443;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

```bash
certbot --nginx -d bh.example.com
```

### Direct HTTPS (no Nginx)

```toml
[api]
bind = "0.0.0.0"
port = 8443
tls_cert = "/etc/banhammer/cert.pem"
tls_key = "/etc/banhammer/key.pem"
```

## Configuration

See [config.example.toml](config.example.toml) for all options.

```toml
[api]
bind = "127.0.0.1"    # Use "0.0.0.0" for direct access (requires TLS)
port = 8443
api_key = "bh_..."     # Generated by 'banhammer-agent init'

[agent]
poll_interval = 60     # Seconds between Fail2Ban polls

[fail2ban]
log_path = "/var/log/fail2ban.log"
client_path = "/usr/bin/fail2ban-client"

[storage]
db_path = "/var/lib/banhammer/banhammer.db"
retention_days = 90    # Auto-delete old events
```

## CLI

| Command | Description |
|---------|-------------|
| `banhammer-agent init` | Generate config and API key |
| `banhammer-agent run` | Start monitoring + API server |
| `banhammer-agent status` | Show local DB stats and API status |

## Requirements

- Python >= 3.10
- Fail2Ban installed and running
- Root access (for fail2ban-client and log access)
